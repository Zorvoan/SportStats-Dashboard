# 4. Týden – Uživatelské funkce a rozšíření systému

## Cíl týdne

Hlavním cílem čtvrtého týdne bylo rozšířit aplikaci o uživatelské funkce, které zlepší práci se sportovními daty. Zaměřili jsme se především na ukládání oblíbených týmů a jezdců, historii vyhledávání a rozšíření možností filtrování výsledků.

---

# Úkoly

## Backend

- Implementace ukládání oblíbených týmů a jezdců.
- Vytvoření endpointů pro správu oblíbených položek.
- Implementace historie vyhledávání uživatelů.
- Ukládání vyhledávacích dotazů do databáze.
- Přidání filtrování výsledků podle parametrů.
- Testování nových API endpointů.
- Optimalizace práce s databází.
- MYSQL Databaze
- REACT

## Frontend

- Vytvoření sekce „Oblíbené“.
- Zobrazení uložených týmů a jezdců.
- Implementace historie vyhledávání.
- Přidání filtrovacích prvků do uživatelského rozhraní.
- Úprava navigace aplikace.
- Vylepšení responzivity aplikace.
- Testování komunikace s backendem.

## Databáze

- MySQL

# Rozdělení práce v týmu

## Project Manager – Patík

- Koordinace vývoje.
- Kontrola plnění stanovených cílů.
- Organizace týmových schůzek.

## Backend Developer – Jančík, Kůra

- Implementace oblíbených položek.
- Správa historie vyhledávání.
- Vývoj a testování API endpointů.
- Optimalizace databázových operací.

## Frontend Developer – Poštulka, Zapletal

- Tvorba uživatelského rozhraní pro oblíbené položky.
- Implementace filtrování výsledků.
- Úprava navigace a designu aplikace.
- Napojení nových funkcí na backend.

## QA & Dokumentace – Zapletal

- Testování nových funkcí.
- Kontrola správnosti ukládání dat.
- Aktualizace projektové dokumentace.
- Evidence nalezených chyb a návrhů na zlepšení.

# Výstup týdne

Na konci čtvrtého týdne aplikace umožňovala ukládání oblíbených týmů a jezdců, zaznamenávání historie vyhledávání a filtrování sportovních výsledků. Uživatelské rozhraní bylo rozšířeno o nové sekce a systém byl připraven na další vývoj administrativních funkcí a pokročilých statistik.
